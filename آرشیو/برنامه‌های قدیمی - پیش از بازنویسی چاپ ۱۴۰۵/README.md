# نسخه‌های قدیمی — فقط برای مراجعه به سوابق

**این فایل‌ها برنامهٔ جاری نیستند و نباید برای اجرای نسخهٔ جدید استفاده شوند.**

این مجموعه عیناً از commit `fc85e03`، پیش از بازنویسی با کتاب‌های چاپ ۱۴۰۵، بازیابی شده است؛ محتوای فایل‌های قدیمی تغییر نکرده است. ۱۹ برنامهٔ تاریخ‌دار در پوشهٔ ماه و تاریخ قبلی و دو برنامهٔ پریمیوم در «تاریخ اعلام‌نشده» قرار دارند. خروجی‌ها و بسته‌های قدیمیِ ریشه و قالب‌های Stitch نیز صرفاً برای حفظ سابقه نگه داشته شده‌اند؛ برخی نسخه‌های تکراری یا قالب‌های متفاوت همان برنامه‌اند.

برای فایل‌های معتبر فقط به [برنامه تحصیلیِ جاری](../../برنامه%20تحصیلی/README.md) مراجعه کنید. فایل `manifest.json` اثرانگشت و مسیر اصلی همهٔ فایل‌های آرشیو را ثبت می‌کند.
