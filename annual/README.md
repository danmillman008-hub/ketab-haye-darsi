# ساخت برنامه‌های سالانه با فرم توصیفیِ قبلی

## مبنا

دستور جاری: منابع فعال ملاک محدوده و نام مباحث؛ فرم توصیفی و فرمول قبلی ثابت. تخصیص روزهای زیست با حفظ گفتارها اصلاح می‌شود؛ صفحات صرفاً برای برابری عددی بریده نمی‌شوند. متن باکس‌های ۱ آبان در این مرحله دست‌نخورده است. [شرح اصلاحات و حدود کنترل](CURRENT_SOURCE_NOTES.md).

## فایل‌ها

- `curriculum.py`: بودجه‌ها، مرز گفتارها و اصلاحات مستند کتاب‌های فعال.
- `data/`: دادهٔ هر آزمون؛ توضیحات داخلی منبع به فایل دانش‌آموز منتقل نمی‌شوند.
- `manifest.json`: مقصد هر برنامه در پوشهٔ ماه و تاریخ آزمون.
- `STYLE_QA.json`: کنترل فرمول، تقویم، باکس‌های ثابت ۱ آبان و متن ممنوع.
- `SOURCE_QA.json`: اثرانگشت منابع، آغاز گفتارها، مرزهای منتخب و پوشش محدوده‌ها.
- `SOURCE_CHANGES.json`: تغییر متن باکس‌ها نسبت به کامیت `5395648`.
- `QA.json`: کنترل فرمول، تاریخ، Word و PDF، متن کامل و رندر مستقل.
- `preserved.json`: اثرانگشت گزارش‌های دانش‌آموز که نباید تغییر کنند.

## قواعد نمایش

نام مبحث/فصل/گفتار + صفحه + دستور کوتاه مطالعه/تست. همان قالب طلایی Stitch14، فونت‌ها و کادرها. شمارهٔ صفحه جای عنوان مبحث نیست. هیچ نام ماز، توضیح تطبیق منابع، حجم محاسبه‌شده، معرفی چاپ جدید یا صفحهٔ توضیحات فنی در Word/PDF دانش‌آموز قرار نمی‌گیرد. عنوان کوتاه «فایل برآیندی» برای استثناها باقی می‌ماند.

## بازتولید از ریشهٔ مخزن

```sh
.venv/bin/python annual/scripts/build_data.py
.venv/bin/python annual/scripts/check_style.py
.venv/bin/python annual/scripts/check_sources.py
# build_word.py را برای همهٔ ۲۱ شناسهٔ manifest اجرا کنید؛ از جمله ۱ آبان:
.venv/bin/python annual/scripts/build_word.py 1405-08-01
node annual/scripts/render.mjs .work/annual/fresh-render
node annual/scripts/render.mjs .work/annual/fresh-independent
.venv/bin/python annual/scripts/validate.py .work/annual/fresh-render .work/annual/fresh-independent
.venv/bin/python annual/scripts/publish.py .work/annual/fresh-render
```

برای هر رندر پوشهٔ تازه به کار ببرید. PDF باید از همان DOCX ساخته شود. کنترل متن همهٔ صفحات، نبود فونت گمشده، تصویر/جدول بومی، شمار باکس‌ها و بازبینی تصویری لازم است؛ اجرای مستقیم Microsoft Word آزموده نشده است.

## تقویم و فرمول

۱۹ آزمون تاریخ‌دار، ۳۹ هفتهٔ پیوسته؛ دو پریمیوم با چهار هفتهٔ نسبی افزوده. هر هفته ۲۷ باکس، ۴۷ ساعت و ۴۹۵ تست. هر هفته دو برگ برنامه دارد؛ کل مجموعه ۸۶ صفحه است، بدون صفحهٔ توضیحات اضافه. برای ماه‌های فاقد تاریخ آزمون، برنامهٔ فرضی ساخته نمی‌شود.
