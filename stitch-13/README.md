## کیفیت Word

- متن و جدول واقعی، بدون قراردادن عکس صفحات به جای سند قابل‌ویرایش.
- عرض ستون و ارتفاع ردیف ثابت، جهت راست‌به‌چپ، جلوگیری از شکستن ردیف و فونت‌های تعبیه‌شده.
- نگهداری رنگ‌های طلایی، ردیف‌های خاکستری روشن گزارش، چهار ستون گزارش و سه ستون برنامه.
- Vazirmatn برای متن فارسی و زیرمجموعهٔ DejaVu Sans برای مربع/دایرهٔ انتخاب؛ مجوزها همراه دارایی‌ها نگهداری شده‌اند.
- هر سه DOCX با LibreOffice WASM رندر شدند: **۴، ۱ و ۱ صفحه، بدون فونت مفقود**. نتیجهٔ ماشینی در [QA.json](QA.json) موجود است.
- رندر برنامه و هر دو فرم گزارش با تصاویر قالب مقایسهٔ بصری شد؛ خروجی اضافه یا سرریز پاورقیِ برگ اول در مرحلهٔ ساخت اصلاح شد.
- Microsoft Word در محیط اجرا موجود نیست؛ رندر مستقیم Word ادعا نمی‌شود. متن/جدول قابل‌ویرایش است و تغییر طول متن توسط کاربر ممکن است به تنظیم ارتفاع خانه نیاز داشته باشد.

## بازتولید از ریشهٔ مخزن

وابستگی‌های Python طبق `../requirements.txt` و ابزارهای Node طبق `../package.json` نصب شوند. سپس:

```sh
.venv/bin/python stitch-13/scripts/build_html.py
npx tailwindcss -c tailwind.config.cjs --content stitch-13/index.html -i assets/input.css -o stitch-13/assets/planner.css --minify
cat assets/overrides.css >> stitch-13/assets/planner.css
node stitch-13/scripts/build_pdf.cjs
.venv/bin/python stitch-13/scripts/build_planner_word.py
.venv/bin/python stitch-13/scripts/build_reports_word.py
.venv/bin/python stitch-13/scripts/validate.py
```

برای رندر واقعی Word و بررسی صفحه‌بندی:

```sh
npm ci --prefix stitch-13
node stitch-13/scripts/render_word.mjs .work/stitch13-qa-new
```

مسیر خروجی QA باید تازه باشد؛ مبدل خروجی موجود را بازنویسی نمی‌کند. PDFهای رندر کنترل، فایل موقت‌اند و PDF نهایی برنامه را جایگزین نمی‌کنند. در محیط کمینه برای Chromium ممکن است تنظیم کتابخانه‌های سیستمی لازم باشد؛ راهنمای مخزن اصلی را ببینید.

پس از کنترل کیفیت:

```sh
.venv/bin/python stitch-13/scripts/package.py
```

فایل‌های قبلی یا کتاب‌های درسی را هنگام ساخت این نسخه بازنویسی/منتشر نکنید.
