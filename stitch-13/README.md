# نسخهٔ سازگار نمونهٔ ۱ آبان

فایل‌های برنامه در این مسیر با نمونهٔ جاری Stitch14 همسان‌اند. [برنامه‌های ماهانه](../برنامه%20تحصیلی/README.md) مرجع تحویل است. قالب‌های این پوشه تاریخی‌اند و برای تولید نسخهٔ جاری استفاده نشوند. فرم‌های گزارش بدون تغییر مانده‌اند.

## اصلاح جاری

نسخهٔ نمونه با برنامهٔ سالانه همسان است؛ گفتار کوتاه همراه مرور مباحث پیشین همان هفته می‌آید. منابع اصلی کتاب‌های جدیدِ پوشهٔ فعال و منبع دوم ماز است؛ توضیحات منابع فقط در Markdown است. کنترل مرجع در `../annual/QA.json` و `../annual/TOPIC_QA.json` ثبت شده است.
