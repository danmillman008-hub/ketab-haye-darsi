# قالب قدیمی Stitch 13 — خارج از تحویل جاری

خروجی‌های قدیمی برنامه (Word، PDF و بستهٔ ZIP) طبق درخواست کاربر حذف شده‌اند تا با نسخهٔ جاری اشتباه نشوند. قالب‌ها، دارایی‌ها و فرم‌های گزارش دانش‌آموز حفظ شده‌اند. کنترل‌های QA قدیمی این پوشه مربوط به نسخهٔ تاریخی‌اند، نه تأیید خروجی جاری.

نسخهٔ معتبر: [برنامه‌های سالانه](../برنامه%20تحصیلی/README.md) و [بستهٔ کامل جدید](../organized-deliverables.zip).

[برنامهٔ جاری ۱ آبان](../stitch-14/plan-1-aban-1405.pdf) با قالب مصوب Stitch 14 ارائه می‌شود. دادهٔ plan.json این پوشه نیز با برنامهٔ جاری همسان می‌شود؛ برای تولید نسخهٔ نهایی از مولد annual استفاده کنید، نه اسکریپت‌های قدیمی این پوشه.
