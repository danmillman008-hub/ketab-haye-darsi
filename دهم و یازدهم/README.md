# برنامه‌های مستقل دهم و یازدهم تجربی

**وضعیت: کل سال تحصیلی ۱۴۰۵–۱۴۰۶ برای هر دو پایه ساخته و منتشر شد؛ ۱۷ برنامه در هر پایه.**

[خلاصهٔ کل سال](سال-کامل.md) · [دانلود همهٔ برنامه‌ها (Word و PDF)](annual-1405-1406.zip) · [نمونه‌های اولیهٔ ۱۵ آبان](SAMPLE_REVIEW.md)

این مجموعه کاملاً جدا از دوازدهم است. پوشه‌های `annual`، `برنامه تحصیلی`، قالب‌های اصلی، نمونه‌های قبلی و ZIP دوازدهم نباید تغییر کنند. استفادهٔ فقط‌خواندنی از قالب و فونت‌های تأییدشده مجاز است.

- [دهم](دهم/README.md)
- [یازدهم](یازدهم/README.md)
- [اصول اختصاصی و تصمیم‌های باز](PRINCIPLES.md)
- `calendar.json`: ۱۷ تاریخ واقعی آزمون برای هر پایه، از صفحات ۴ و ۵ PDF همان پایه.
- `sources.json`: شناسه و اثرانگشت دو فایل ماز؛ PDFهای منبع خارج از Git می‌مانند.
- `annual/budget.json`: ردیف‌های بودجهٔ هر ۱۷ آزمون برای دو پایه، رونویسی‌شده از فایل ماز.
- `annual/geology_source.json`: شناسه و اثرانگشت کتاب زمین‌شناسی یازدهم.
- `annual/year_manifest.json`: فهرست ۳۴ برنامهٔ سالانه؛ `annual/YEAR_QA.json` نتیجهٔ کنترل کیفیت.
- `scripts/check_year.py` و `scripts/publish_year.py`: کنترل و انتشار سالانه با دو رندر مستقل.
- `preserved.json`: اثرانگشت فایل‌های موجود پیش از شروع این مجموعه.
- `scripts/check_preserved.py`: اثبات دست‌نخوردن مجموعهٔ قبلی.

پوشهٔ هر تاریخ آزمون، Word و PDF همان برنامه را دارد. پوشه‌های ماهِ بدون آزمون (تیر، مرداد، شهریور) خالی می‌مانند و تاریخ فرضی ساخته نشده است. برنامهٔ ۲۴ اردیبهشت یک‌هفته‌ای است، ۲۵ دی چهارهفته‌ای و ۲۸ خرداد پنج‌هفته‌ای؛ این فاصله‌ها همان فاصلهٔ واقعی تقویم ماز است.
