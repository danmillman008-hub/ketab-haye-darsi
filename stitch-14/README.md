# نمونهٔ ۱ آبان — فرم توصیفیِ مورد تأیید

- [PDF](plan-1-aban-1405.pdf) · [Word قابل‌ویرایش](plan-1-aban-1405.docx)
- [نمایش HTML مرجع](index.html)
- [تمام برنامه‌ها به تفکیک ماه](../برنامه%20تحصیلی/README.md)

متن باکس‌ها و تقسیم روزها از نسخهٔ پیش از بازنویسی بازیابی شده است. نام مباحث، فصل‌ها و گفتارها حفظ شده‌اند؛ اشاره به منبع آزمون و توضیحات فنی در فایل دانش‌آموز حذف شده است. فرمول دو هفته: ۹۴ ساعت و ۹۹۰ تست. فایل PDF از همان Word ساخته می‌شود.

گزارش‌های دانش‌آموز تغییر نکرده‌اند. کنترل جاری این برنامه در `../annual/QA.json` و مقایسهٔ محتوا با نمونهٔ قبلی در `../annual/STYLE_QA.json` ثبت شده است. برای تولید همهٔ برنامه‌ها از راهنمای `../annual/README.md` استفاده کنید.

## اصلاح جاری

نسخهٔ نمونه با برنامهٔ سالانه همسان است؛ گفتار کوتاه همراه مرور مباحث پیشین همان هفته می‌آید. منابع اصلی کتاب‌های جدیدِ پوشهٔ فعال و منبع دوم ماز است؛ توضیحات منابع فقط در Markdown است. کنترل مرجع در `../annual/QA.json` و `../annual/TOPIC_QA.json` ثبت شده است.
