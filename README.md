فرم طلایی و نام مباحث حفظ شده‌اند. برنامه‌های ماه‌ها با کتاب‌های فعال بررسی شده‌اند؛ محدوده‌های نیازمند اصلاح و توزیع زیست در مرز گفتارها اصلاح شده، بدون تغییر ساعت، تست و ترتیب درس‌ها. در ۱ آبان، گفتار کوتاهِ روز آخر همراه مرور گفتارهای پیشین همان هفته آمده است؛ تقسیم عددی اجباری کنار گذاشته شد. توضیحات منابع و شمار حجم صفحات وارد فایل دانش‌آموز نمی‌شود.

## منابع و روش جاری

**کتاب‌های درسی جدیدِ پوشهٔ فعال، منبع اصلی‌اند؛ ماز منبع دوم برای بودجه‌بندی و تقویم است.** مطابق خواستهٔ کاربر، این توضیح فقط در Markdown نوشته شده است و در فایل دانش‌آموز نمی‌آید.

روش برنامه‌نویسی مبحث‌محور است: گفتار کامل + مرور هدفمند، نه تکه‌کردن گفتارها برای برابرشدن صفحات. ساعت، تعداد تست، ترتیب باکس‌ها، قالب طلایی و گزارش‌های دانش‌آموز حفظ شده‌اند. اصلاح‌های معتبرِ کتاب‌های جدید نیز حفظ شده‌اند.
