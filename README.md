## نسخهٔ سوم — منبع اصلاح‌شده و Word

- ترتیب باکس‌ها از راست به چپ، ردیف بالا و سپس ردیف پایین است: **زیست، ریاضی، زیست، ریاضی، زیست**؛ روزهای دیگر: **فیزیک، شیمی، فیزیک، شیمی**. ترتیب مطالعه و تست هر درس حفظ شده است.
- خانه‌های باقی‌مانده عین فرم خام هستند: چک‌باکس، عنوان «درس و مبحث»، جای خالی ساعت و تست؛ هیچ متن جایگزین یا علامت «بدون باکس» ندارند.
- تعداد باکس‌ها، تست‌ها و بودجهٔ آزمون ثابت است؛ در آخرین اصلاح، فقط زمان باکس‌های تست زیست از ۱ به ۲ ساعت افزایش یافت و مجموع ساعت‌ها اصلاح شد.
- منبع فیزیک دهم با `C110214_0.pdf`، چاپ نهم ۱۴۰۳ جایگزین شد. فصل ۲، ص ۲۳–۵۲ با بودجهٔ ماز مطابق است؛ عنوان مستقل «نانو» از برنامهٔ قدیمی حذف شد.
- فایل DOCX دارای متن و جدول قابل‌ویرایش، چیدمان راست‌به‌چپ و چهار برگ طراحی‌شده است؛ تصویر PDF داخل Word نیست. صفحه‌بندی Word ممکن است با فونت و نسخهٔ نرم‌افزار تغییر کند؛ PDF مرجع چاپ ثابت است.

## محدوده و تصمیم‌ها

- هفتهٔ اول: شنبه ۱۸ تا جمعه ۲۴ مهر ۱۴۰۵، دوازدهم؛ هفتهٔ دوم: شنبه ۲۵ مهر تا جمعه ۱ آبان، دهم.
- این بازه، دو هفتهٔ کامل منتهی به آزمون است؛ برنامه از تاریخ امروز شروع نشده و فشرده‌سازی نشده است.
- شنبه، دوشنبه، چهارشنبه: زیست و ریاضی؛ یکشنبه، سه‌شنبه، پنجشنبه: فیزیک و شیمی.
- جمعهٔ ۲۴ مهر: آزمون تمرینی دوازدهم و تحلیل؛ جمعهٔ ۱ آبان: آزمون ماز و تحلیل. آزمون تمرینی ۲۴ مهر، آزمون رسمی دیگری از ماز معرفی نشده است.
- آخرین پیام کاربر ملاک تعارض توصیه‌هاست: درسنامهٔ ریاضی **۱ ساعت**، شیمی **۲۵ تست** در هر باکس. فیزیک مطابق توضیح تفصیلی: یک درسنامهٔ ۲ساعته و پنج باکس تست.
- مدت هر باکس ۲۰تستی زیست طبق آخرین دستور کاربر **۲ ساعت** است؛ مطالعهٔ متن کتاب زیست همچنان ۱ ساعت است. تحلیل در زمان باکس لحاظ شده است. زمان استراحت و آزمون جزو جمع ساعت نیست.
- برای هر هفته: زیست ۹ باکس و ۱۲۰ تست؛ ریاضی ۶ باکس و ۱۵۰ تست؛ فیزیک ۶ باکس و ۱۵۰ تست؛ شیمی ۶ باکس و ۷۵ تست. جمع: **۴۷ ساعت و ۴۹۵ تست**؛ کل دوره **۹۴ ساعت و ۹۹۰ تست** بدون آزمون‌ها.
- ریاضی در خود باکس‌ها بدون نام پایه و به‌صورت مبحثی نوشته شده است. یک درسنامه برای کل مبحث اصلی هفته و پنج باکس تست زیرمبحثی دارد.
- زمین‌شناسی در بودجهٔ ماز هست، ولی مطابق درخواست برنامه فقط چهار درس دارد؛ بنابراین پوشش کامل همهٔ دروس آزمون ادعا نمی‌شود.

- زیست دوازدهم: سه گفتار نوکلئیک‌اسیدها (ص ۱–۸ با مقدمه)، همانندسازی دنا (۹–۱۴)، پروتئین‌ها (۱۵–۲۰)، یک گفتار در هر روز زیست.
- زیست دهم: پنج گفتار؛ فصل ۲ گفتارهای ۲ و ۳ (۲۵–۳۲)، فصل ۳ گفتارهای ۱ و ۲ با مقدمه (۳۳–۴۴)، فصل ۳ گفتار ۳ (۴۵–۴۶). تقسیم ۲+۲+۱؛ بدون افزودن گفتار اول گوارش خارج از بودجه.

- شیمی دهم: ۲۸ صفحه، تقسیم ۱۰+۹+۹: ۱۹–۲۸، ۲۹–۳۷، ۳۸–۴۶.

فهرست پوشه ۱۷ فایل داشت: متن توصیه‌ها، ZIP قالب، PDF ماز و ۱۴ PDF کتاب. فایل‌ها دریافت و عنوان/پایهٔ آنها بررسی شد؛ فهرست و صفحات مرتبط با بودجه مبنای برنامه قرار گرفت، نه مطالعهٔ کامل همهٔ کتاب‌ها.

- زیست: `C11216.pdf`، `C110216.pdf`، `000-160-C111216.pdf` (یازدهم، خارج از انتخاب این دوره).
- شیمی: `C112210.pdf`، `C111210.pdf`، `C110210.pdf` و `C110210 (1).pdf`؛ برای دهم نسخهٔ بدون پسوند مبناست.
- ریاضی: `C112211.pdf`، `C111211.pdf`، `C110211.pdf` و `C110211 (1).pdf`؛ نسخهٔ بدون پسوند دهم مبناست. بخش‌های تابع و درجهٔ دوم یازدهم با وجود انتخاب دهم، طبق بودجهٔ مبحثی ماز لحاظ شده‌اند.
- فیزیک: `C112244.pdf`، `C111244.pdf`، `C110214_0.pdf` (جایگزین نسخهٔ قدیمی)؛ یازدهم خارج از انتخاب این دوره است.

## بازتولید

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
npm ci
.venv/bin/python scripts/build.py
npm run css
npm test
npm run pdf
.venv/bin/python scripts/build_docx.py
.venv/bin/python scripts/validate_outputs.py
.venv/bin/python scripts/package.py
```

`npm run pdf` از Chromium بستهٔ npm استفاده می‌کند؛ سیستم باید کتابخانه‌های لازم اجرای Chromium را داشته باشد. برای نمایش HTML کافی است `index.html` را باز کنید؛ یا با `python -m http.server 8000 --bind 0.0.0.0` سرو کنید. خروجی PDF موجود آمادهٔ استفاده است.
