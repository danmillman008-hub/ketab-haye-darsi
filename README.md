## محدوده و تصمیم‌ها

- هفتهٔ اول: شنبه ۱۸ تا جمعه ۲۴ مهر ۱۴۰۵، دوازدهم؛ هفتهٔ دوم: شنبه ۲۵ مهر تا جمعه ۱ آبان، دهم.
- این بازه، دو هفتهٔ کامل منتهی به آزمون است؛ برنامه از تاریخ امروز شروع نشده و فشرده‌سازی نشده است.
- شنبه، دوشنبه، چهارشنبه: زیست و ریاضی؛ یکشنبه، سه‌شنبه، پنجشنبه: فیزیک و شیمی.
- جمعهٔ ۲۴ مهر: آزمون تمرینی دوازدهم و تحلیل؛ جمعهٔ ۱ آبان: آزمون ماز و تحلیل. آزمون تمرینی ۲۴ مهر، آزمون رسمی دیگری از ماز معرفی نشده است.
- آخرین پیام کاربر ملاک تعارض توصیه‌هاست: درسنامهٔ ریاضی **۱ ساعت**، شیمی **۲۵ تست** در هر باکس. فیزیک مطابق توضیح تفصیلی: یک درسنامهٔ ۲ساعته و پنج باکس تست.
- مدت هر باکس ۲۰تستی زیست **۱ ساعت پیشنهادی** است؛ کاربر برای این باکس مدت مشخص نکرده بود. تحلیل در زمان باکس لحاظ شده است. زمان استراحت و آزمون جزو جمع ساعت نیست.
- برای هر هفته: زیست ۹ باکس و ۱۲۰ تست؛ ریاضی ۶ باکس و ۱۵۰ تست؛ فیزیک ۶ باکس و ۱۵۰ تست؛ شیمی ۶ باکس و ۷۵ تست. جمع: **۴۱ ساعت و ۴۹۵ تست**؛ کل دوره **۸۲ ساعت و ۹۹۰ تست** بدون آزمون‌ها.
- ریاضی در خود باکس‌ها بدون نام پایه و به‌صورت مبحثی نوشته شده است. یک درسنامه برای کل مبحث اصلی هفته و پنج باکس تست زیرمبحثی دارد.
- زمین‌شناسی در بودجهٔ ماز هست، ولی مطابق درخواست برنامه فقط چهار درس دارد؛ بنابراین پوشش کامل همهٔ دروس آزمون ادعا نمی‌شود.

### تقسیم زیست و شیمی

- زیست دوازدهم: سه گفتار نوکلئیک‌اسیدها (ص ۱–۸ با مقدمه)، همانندسازی دنا (۹–۱۴)، پروتئین‌ها (۱۵–۲۰)، یک گفتار در هر روز زیست.
- زیست دهم: پنج گفتار؛ فصل ۲ گفتارهای ۲ و ۳ (۲۵–۳۲)، فصل ۳ گفتارهای ۱ و ۲ با مقدمه (۳۳–۴۴)، فصل ۳ گفتار ۳ (۴۵–۴۶). تقسیم ۲+۲+۱؛ بدون افزودن گفتار اول گوارش خارج از بودجه.
- شیمی دوازدهم: ۲۴ صفحه در سه بخش ۸صفحه‌ای؛ در صفحهٔ ۲۴ ورود به pH ممنوع است.
- شیمی دهم: ۲۸ صفحه، تقسیم ۱۰+۹+۹: ۱۹–۲۸، ۲۹–۳۷، ۳۸–۴۶.

## بازتولید

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
npm ci
.venv/bin/python scripts/build.py
npm run css
npm test
npm run pdf
.venv/bin/python scripts/build_docx.py
.venv/bin/python scripts/validate_outputs.py
.venv/bin/python scripts/package.py
```

`npm run pdf` از Chromium بستهٔ npm استفاده می‌کند؛ سیستم باید کتابخانه‌های لازم اجرای Chromium را داشته باشد. برای نمایش HTML کافی است `index.html` را باز کنید؛ یا با `python -m http.server 8000 --bind 0.0.0.0` سرو کنید. خروجی PDF موجود آمادهٔ استفاده است.
